# Icebox

Where ideas wait.

## Rules

Anything that occurs to you mid-build and is not already in `BACKLOG.md` goes here
immediately, in one line, and is not discussed further until the current milestone ships.

Nothing leaves this file mid-milestone. Not small things, not quick things, not things
that would only take ten minutes. The ten minute things are how a clean codebase turns
into the one nobody can maintain.

At the end of each milestone, read this file and decide. Most entries will be deleted
rather than promoted, and that is the point. Deleting is a real outcome, not a failure.

Format: one line, dated, no justification. If it needs a paragraph to explain why it is
worth doing, it is not obviously worth doing.
